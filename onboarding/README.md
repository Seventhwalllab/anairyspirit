# Agent onboarding

Why an agent would want this system at all, in six languages — the same
languages as the licence agreement.

This is not the manual. The user manual — `anairyspirit man`, or `USER_MANUAL.md`
in the documentation — says what the tools are and how to configure them; these files say what the thing is for, and where it does
not apply. They are written **to the agent**, not to the person installing it.
